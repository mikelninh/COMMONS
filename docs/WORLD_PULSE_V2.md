# WORLD PULSE v2 — Cinematic Action Experience

WORLD PULSE v2 changes the public surface from a dense command-center dashboard into a cinematic Earth observatory.

## Product idea

**Planet first. Story second. Evidence underneath.**

A viewer should be able to understand one meaningful chain without reading a dashboard:

```text
Something changed
→ people may be affected
→ the claim is verified
→ a responder is identified
→ action is underway
→ outcome evidence appears
→ the loop remains open
```

## Action 001 story

The first reusable story is **Nepal · Flash Floods 2026**.

Scenes:

1. Signal
2. Human impact
3. Verify
4. Response
5. Evidence of response
6. Response capacity
7. You

Every scene can specify:

- narrative type,
- headline / metric,
- source note,
- camera position,
- autoplay duration,
- action buttons.

The action is deep-linked through:

`?action=nepal-flash-floods-2026&scene=<scene-id>`

## Interaction

- Autoplay cinematic story
- Previous / next / pause controls
- Clickable progress rail
- Arrow-key navigation
- Space to pause/play
- Escape to close layers
- Reduced-motion support
- Live Earth signal exploration
- Evidence / trust drawer
- Generated 16:9 share card
- Native share when supported

## Visual rules

- Reduce dashboard chrome.
- Use space, scale and typography before borders.
- Keep Earth as the primary visual object.
- Motion should happen because meaning changed, not because the interface is idle.
- Amber means attention.
- Green means documented improvement / response evidence.
- Red is reserved for harm when needed.
- Do not use color as the only information channel.

## Trust rules

- Never fake live data.
- Separate event magnitude from human impact.
- Preserve the uncertainty language of estimates.
- Keep historical claims dated.
- Never imply a user's contribution caused an outcome without causal evidence.
- Keep primary evidence one click away.
- An unresolved operation remains an **OPEN LOOP**.

## Definition of done

The public experience should let a first-time viewer answer:

1. What happened?
2. How do we know?
3. Who is responding?
4. What response exists?
5. What measurable evidence shows the response reached people?
6. What can I do?
7. Where can I inspect the evidence?
8. How do I follow what happens next?

The long-term reusable primitive is not a Nepal page. It is the **story engine for accountable action loops**.
