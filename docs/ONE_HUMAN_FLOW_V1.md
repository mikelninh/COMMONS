# WORLD PULSE — One Human Flow v1

## Product promise

In under two minutes, a person should be able to understand one important change in the world, know why it matters, know how certain we are, and know whether there is anything useful they can do.

On return, they should be able to see what changed since they last looked.

## Primary journey

**Orient → Understand → Decide → Follow → Return**

### 1. Orient

Home answers:

- What changed?
- Which stories are worth knowing?
- Which stories show progress?
- Is there a verified public action path?
- Is the evidence currently healthy?

The user should not need to understand COMMONS architecture.

### 2. Understand

Each story answers:

- What happened?
- Why does it matter?
- What did people do?
- Is it working?
- What now?

Evidence is embedded at the claim level with a simple **How do we know?** interaction.

### 3. Decide

Every story ends with:

**Does this need anything from you?**

Possible outcomes:

- a single verified direct action
- follow the story
- nothing useful is required right now

COMMONS must be comfortable telling a user that no direct action is verified.

### 4. External action handoff

If the user chooses an external action, COMMONS explains:

- the user is leaving COMMONS
- which official path is being opened
- what COMMONS can verify
- what COMMONS cannot verify

Only then does the user continue.

### 5. Follow

A follow is stored locally with the evidence date that existed at that time.

### 6. Return

Home exposes **Since you were here**.

If the story has a newer evidence date, it becomes:

**New official evidence is available**

The user can jump back near the outcome/decision portion of the story.

## Trust

Trust is primarily ambient.

Normal story UI shows:

- source
- date
- claim type
- limitation
- How do we know?

The full Trust system remains available as deep inspection, not a required step.

## Action system

Action Loop remains an internal/product architecture:

problem → evidence → actor → intervention → action → outcome → learning

But normal users experience it as:

**Does this need anything from me?**

## Success criteria

A healthy session can be:

1. Open WORLD PULSE.
2. Read one story.
3. Learn that nothing useful is required.
4. Leave in under two minutes.

Time-on-site is not the objective.

## Safety properties retained

- provenance
- stale-data degradation
- source limitations
- explicit uncertainty
- no invented action
- no causal overclaiming
- self-reported external completion
- trust-gated direct actions
- incident history
- full audit depth
